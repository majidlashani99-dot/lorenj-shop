فونت‌های سایت (برای حالت آفلاین)
================================
این دو فایل را از fonts.google.com دانلود کنید و با همین نام‌ها داخل همین پوشه بگذارید:

1) Lalezar  (فونت تیتر و اعداد درشت)  ->  Lalezar-Regular.ttf
2) Vazirmatn (فونت متن)               ->  Vazirmatn.ttf   (فایل Variable را به این نام تغییر دهید)

اگر فایل‌ها نباشند، سایت خودکار از فونت‌های سیستم (Tahoma / Segoe UI) استفاده می‌کند.
وقتی سایت روی هاست رفت و آنلاین شد، لینک گوگل‌فونت داخل index.html هم خودکار کار می‌کند.
